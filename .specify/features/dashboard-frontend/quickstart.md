# Quickstart Guide for Galaxify Dashboard Front-End

This guide provides a quick overview to get started with the Galaxify Dashboard Front-End development.

## 1. Setup

1. Clone the repository.
2. Navigate to the `packages/web` directory.
3. Install dependencies using pnpm: `pnpm install`

## 2. Running the Application

To start the development server:

```bash
pnpm dev
```

## 3. Mock Data

This feature currently uses mock data. Details on how to interact with or modify the mock data will be provided here once defined.

## 4. Testing

To run tests for the frontend:

```bash
pnpm test
```
